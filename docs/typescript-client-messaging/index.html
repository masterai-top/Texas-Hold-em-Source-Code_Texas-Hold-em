TypeScript 德州扑克客户端消息层

从消息模型、事件定义和事件绑定三个入口，说明客户端如何处理大厅、入桌、重连、房间状态与比赛消息。

查看消息代码

客户端模块职责

消息构造与解析

MsgHandlerModel.ts 引用 Hall、Login、User、GameRecord、MTT 等 Protobuf 模块。

事件分发

EventBind.ts 处理房间登录、进入比赛房和游戏开始等事件。

状态常量

Const.ts 定义 MTT、SNG 房间类型与比赛状态。

界面与消息对应

客户端不只是显示牌桌。截图可见聊天、手牌、公共牌和操作按钮；消息层则负责把房间列表、牌局事件和状态变化送到界面模块。

仓库展示的是关键 TypeScript 模块。是否包含完整 UI 资源、构建脚本和所有依赖，应按源码交付清单确认。
