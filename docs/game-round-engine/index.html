C++ 德州扑克游戏核心源码

本专题聚焦德州牌局的代码生命周期：检查开局、开始计时、发牌、回合计算、牌局结束，再把结果送回房间服务和客户端。

从代码文件理解牌局流程

开始条件

core/checkbegin.h 检查能否开局并处理需要移除的玩家。

计时器

core/begintimer.h 与 core/endtimer.h 管理阶段时间和回调。

发牌与胜牌

core/sendhdcard.h 负责手牌发送及赢家牌面设置入口。

计算与结束

gamecalculate.h、gameend.h 组成结算及结束上报路径。

配置与房间通信

gameconfig.cpp 读取座位、盲注、行动时间、最大局数及房间类型；gameserver.cpp 则在游戏核心与房间服务之间转发消息、广播和旁观数据。
